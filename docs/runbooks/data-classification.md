# Data Classification

Referenced by SOC2 control C1.1. Draft policy — not yet mapped per-field
against the data model (tracked as a gap-analysis note, not a numbered
remediation item since it's scoped to future services rather than
`sample-app`, which holds no persistent data today).

| Class | Examples | Handling |
|---|---|---|
| Public | Marketing content, published docs | No restriction |
| Internal | Architecture docs, non-sensitive logs | Internal repos/wikis only |
| Confidential | Credentials, customer PII, audit evidence packages | Encrypted at rest, access logged, retention per [remediation-roadmap.md](../../compliance/soc2/remediation-roadmap.md) item R-5 once automated |
| Restricted | Signing keys, root/admin credentials | Hardware-backed storage or secrets manager only; never in source, see [gitleaks.toml](../../security/secrets/gitleaks.toml) |

Compliance evidence packages generated by
[`collect_evidence.py`](../../compliance/evidence-collector/collect_evidence.py)
are **Confidential** — they enumerate control implementation status and
should not be shared outside the org without legal review (see CC2.3 gap).
